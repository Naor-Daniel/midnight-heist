# Midnight Heist

A six-level stealth game that runs entirely in the browser. No server, backend, database, or API keys are needed.

## Play

Use the arrow keys or WASD to move. Collect every diamond and, where required, the access card before reaching the exit. Pick up optional intel for ten extra seconds. Press **E** near a security console to shut down cameras and lasers for eight seconds. Use **Space** for a smoke gadget. Avoid guard sight cones, cameras, and lasers.

Choose Rookie, Agent, or Legend to set how long you can remain in radar before capture: 1.5, 0.8, or 0.4 seconds respectively. Guards also get faster and the clock shorter as difficulty rises.

The soundtrack and effects are generated in the browser with Web Audio. Use **SOUND ON/OFF** at the top of the page to mute or unmute them.

Open `index.html` directly, or publish the repository root with GitHub Pages.
